# Rule: Strict Fact-Checking

When generating or reviewing educational content for this repository:

1. **No Medical Hallucinations:** If you do not know the answer regarding a medical procedure, drug, or tumor type (e.g., Pineal Gland tumors), use your web search tools to consult reputable sources (NCI, COG, SickKids).
2. **Cite Sources:** Append references to authoritative pediatric oncology institutions for any medical claims made in the documentation.
3. **Clear Disclaimers:** Ensure that any patient-facing content includes standard disclaimers that the platform is for educational purposes and not a substitute for professional medical advice.
