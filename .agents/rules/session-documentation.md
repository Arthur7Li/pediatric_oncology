# Rule: Mandatory Session Documentation

1. **Continuous Record:** To ensure full transparency and prevent hidden inconsistencies, all agents must document significant changes, decisions, or new feature implementations in `docs/SESSION_LOG.md`.
2. **Format:** Each entry must include the date, a precise timestamp (e.g., **[17:40]**), and a brief, clear summary of the work done in that session.
3. **Synchronization:** Before beginning new work, agents should review `docs/SESSION_LOG.md` to ensure they are on the same page with past workflows.
